# 气象可视化三合一仪表盘

统一的天气可视化 Web 应用，包含三个视图，一键切换。

## 三个视图

| Tab | 名称 | 说明 |
|-----|------|------|
| 1 | 极简天气卡 | 磨砂玻璃风格，大数字温度，24h 趋势图，5 日预报 |
| 2 | 地球风场 | Leaflet 地图 + Canvas 风场粒子动画 |
| 3 | 卫星仪表盘 | 风云四号卫星云图背景 + 数据叠加（默认视图） |

## 数据源

- **Open-Meteo** — 实时气象数据（温度、湿度、风速、气压等）
- **FY-4A 风云四号** — 中国区域卫星云图（每 15 分钟更新）
- **Himawari-8 向日葵** — 亚太高清卫星云图（可见光 / 红外）

全部免费，无需 API Key。

## 技术栈

- React 19 + Vite + TypeScript
- Tailwind CSS v4
- Recharts（图表）
- Leaflet（地图）
- Canvas API（风场粒子动画）

## 本地开发

```bash
npm install
npm run dev
```

## 构建部署

```bash
npm run build
# 产出在 dist/ 目录，可部署至任意静态托管
```

## 功能

- 三个视图一键切换，默认卫星仪表盘
- 城市搜索（Open-Meteo Geocoding API）
- 天气代码 → 主题色自动切换（晴天暖橙、阴天灰蓝、雨天冷青）
- 毛玻璃 UI，响应式适配手机和桌面
- 风场粒子 Canvas 动画，基于实际风速和风向生成
